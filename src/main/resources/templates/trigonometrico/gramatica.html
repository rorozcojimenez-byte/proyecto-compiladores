1. Gramática propuesta

Las siguientes producciones definen las reglas sintácticas de las expresiones.

N.º Producción Descripción
1.<E> → <T> <A>Expresión
2.<A> → + <T> <A>Suma
3.<A> → - <T> <A>Resta
4.<A> → εFin de suma o resta
5.<T> → <F> <B>Término
6.<B> → * <F> <B>Multiplicación
7.<B> → / <F> <B>División
8.<B> → εFin de multiplicación o división
9.<F> → + <F>Signo positivo
10.<F> → - <F>Signo negativo
11.<F> → <P>Factor
12.<P> → <R> <C>Potencia
13.<C> → ^ <F>Exponente
14.<C> → εSin exponente
15.<R> → NUMNúmero real
16.<R> → VARVariable
17.<R> → ( <E> )Agrupación
18.<R> → SIN ( <E> )Seno
19.<R> → COS ( <E> )Coseno
20.<R> → TAN ( <E> )Tangente
Nota: ε representa la cadena vacía. NUM representa números reales y VAR representa variables.

6. Comprobación de disyunción de SELECT

Para comprobar que la gramática es LL(1), se comparan los conjuntos SELECT de las producciones que pertenecen al mismo no terminal.

No terminal Producciones Intersección Resultado
A 2, 3 y 4 ∅ Disyuntos
B 6, 7 y 8 ∅ Disyuntos
F 9, 10 y 11 ∅ Disyuntos
C 13 y 14 ∅ Disyuntos
R 15, 16, 17, 18, 19 y 20 ∅ Disyuntos
¿Por qué es LL(1)?
Los conjuntos SELECT de las producciones alternativas de cada no terminal son disyuntos entre sí. Por lo tanto, al observar un único símbolo de entrada, es posible determinar qué producción aplicar sin ambigüedad en la elección predictiva.
Conclusión: la gramática cumple la condición LL(1).
